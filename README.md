
## 🧠 Глубокая проработка: лизинговый движок (Qumyrsqa Leasing Engine)

  В рамках MVP реализован модуль финансовой логики, который доказывает жизнеспособность архитектуры **0% Hardcode**.  отличие от классических порталов, где формулы «зашиты» в программный код, в QumyrsqaCore расчеты являются частью **Генезис-Атома**.

### 1. Архитектурное соответствие ТЗ
Реализация полностью покрывает следующие требования заказчика:
* **Пункт [276]**: Наличие расчетных инструментов в личном кабинете.
* **Пункт [349]**: Возможность настройки расчетных полей без программирования.
* **Пункт [352]**: Использование встроенных калькуляторов в подсистеме управления услугами.

### 2. Математическая модель
Движок интерпретирует поле `logic_math` из JSON-атома и применяет формулу аннуитетного платежа для лизинга оборудования (вагонов).

где:
* **P (Principal)**: Общая сумма финансирования (вычисляется динамически).
* **r (Rate)**: Месячная процентная ставка.
* **n (Periods)**: Срок лизинга в месяцах.

### 3. Механика No-code изменений
для изменения условий финансового продукта администратору Холдинга достаточно изменить одно значение в файле `leasing_v1.json`. 
**Результат:** все пользователи портала мгновенно видят обновленные расчеты без пересборки (deploy) и остановки системы.
