
## 🧠 лубокая проработка: изинговый вижок (Qumyrsqa Leasing Engine)

 рамках MVP реализован модуль финансовой логики, который доказывает жизнеспособность архитектуры **0% Hardcode**.  отличие от классических порталов, где формулы «зашиты» в программный код, в QumyrsqaCore расчеты являются частью **енезис-тома**.

### 1. рхитектурное соответствие Т
еализация полностью покрывает следующие требования аказчика:
* **ункт [276]**: аличие расчетных инструментов в ичном кабинете.
* **ункт [349]**: озможность настройки расчетных полей без программирования.
* **ункт [352]**: спользование встроенных калькуляторов в подсистеме управления услугами.

### 2. атематическая модель
вижок интерпретирует поле `logic_math` из JSON-атома и применяет формулу аннуитетного платежа для лизинга оборудования (вагонов).

де:
* **P (Principal)**: бщая сумма финансирования (вычисляется динамически).
* **r (Rate)**: есячная процентная ставка.
* **n (Periods)**: Срок лизинга в месяцах.

### 3. еханика No-code изменений
ля изменения условий финансового продукта администратору Холдинга достаточно изменить одно значение в файле `leasing_v1.json`. 
**езультат:** се пользователи портала мгновенно видят обновленные расчеты без пересборки (deploy) и остановки системы.
